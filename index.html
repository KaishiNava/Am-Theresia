ABOUT THERESIA AM

ENGINE CORE

Theresia AM Suite adalah sistem otentikasi otomatis berbasis API modern yang dirancang khusus untuk memproses pengiriman serta verifikasi token tanpa batas akses standar.

Dengan integrasi Serverless Proxy Engine, platform ini membebaskan pengguna dari kendala Rate Limit browser, kendala CORS, serta masalah pemblokiran domain publik.

Instructions
CARA PENGGUNAAN
01. Input Email

Masukkan alamat email Anda pada tab AM Generator dan tekan "Send Magic Link".

02. Salin Link Verifikasi

Buka inbox/spam email Anda. Salin (copy address) tautan Magic Link penuh dari email tersebut.

03. Tempel & Verifikasi

Kembali ke web ini, tempelkan link pada form Step 2 lalu tekan "Verify Account".

Endpoints
DOKUMENTASI API
GET /api/cookie

Mengambil session cookie aman dari server backend.

POST /api/send

Mengirimkan permintaan link verifikasi ke email target.

POST /api/verify

Memvalidasi token & magic link untuk otentikasi user data.
